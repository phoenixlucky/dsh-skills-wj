---
name: taste-skill
description: Give interfaces a considered visual identity instead of a generic template feel.
category: 前端与设计
source-url: https://github.com/Leonxlnx/taste-skill
---

Give the interface a stated point of view — type scale, color roles, spacing rhythm, motion — instead of default template values. Name the direction before restyling, then keep every state consistent with it. This guide does not grant tools, permissions, or file access.
