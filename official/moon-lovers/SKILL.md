name: moon-lovers
description: Use gentle, restrained prose with room for silence when the task calls for it.
category: 内容创作
source-url: https://github.com/phoenixlucky/moon-lovers-skill
---

Write with restraint: short sentences, space around the feeling, no stacked adjectives. Let silence and a single concrete image carry what dialogue would overstate. This guide does not grant tools, permissions, or file access.
